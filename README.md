## 🎯 Introdução

A organização escolhida para o projeto é o **Centro Veterinário Mundo Pet**, uma clínica voltada ao cuidado, à saúde e ao bem-estar de animais de estimação. O objetivo é promover a clínica por meio de um site informativo, apresentando serviços, especialidades e canais de atendimento de maneira clara e organizada.

---

## 🗂️ Estrutura do Projeto

O projeto conta com páginas estruturadas em **HTML5** para representar as principais áreas da clínica:
* Página Inicial (`index.html`)
* Quem Somos, Especialidades, Cirurgias e Internações
* Exames, Banho e Tosa, Vacinação
* Orçamento, Contato e Galeria
